Themes UTS Fiza

## 1. Nama Tema
Themes UTS Fiza

## 2. Deskripsi
Themes UTS Fiza merupakan tema WordPress yang dikembangkan untuk memenuhi tugas UTS dengan mengusung desain modern tech dan kombinasi warna hijau sage serta hijau tua. Tema ini dirancang dengan tampilan yang sederhana, rapi, dan responsif sehingga nyaman digunakan di berbagai perangkat. Selain itu, tema ini dilengkapi dengan halaman utama, daftar artikel, halaman detail artikel, menu navigasi, dan sidebar untuk memudahkan pengunjung menjelajahi website. Themes UTS Fiza dibuat sebagai website pribadi dan informasi yang dapat digunakan untuk berbagi cerita, pengalaman, pengetahuan, serta berbagai informasi yang bermanfaat bagi pembaca.

## 3. Fitur
- Tampilan halaman utama dengan desain modern.
- Bagian hero sebagai pengenalan website.
- Menampilkan artikel terbaru.
- Halaman detail artikel.
- Halaman statis dan arsip artikel.
- Navigasi menu utama.
- Sidebar berisi pencarian, kategori, dan tulisan terbaru.
- Mendukung gambar unggulan pada artikel.
- Desain responsif untuk berbagai ukuran layar.
- Warna dominan hijau sage dan hijau tua.

## 4. Teknologi yang Digunakan
- WordPress
- PHP
- HTML
- CSS
- MySQL/MariaDB sebagai database WordPress

## 5. Struktur File
- style.css: Mengatur tampilan dan desain tema.
- functions.php: Mengatur fitur dan konfigurasi tema.
- header.php: Menampilkan bagian kepala website dan navigasi.
- footer.php: Menampilkan bagian bawah website.
- front-page.php: Mengatur tampilan halaman utama.
- home.php: Menampilkan daftar artikel.
- single.php: Menampilkan detail artikel.
- page.php: Menampilkan halaman statis.
- archive.php: Menampilkan arsip artikel.
- index.php: Template cadangan tema.
- sidebar.php: Menampilkan sidebar.
- comments.php: Mengatur tampilan komentar.

## 6. Petunjuk Instalasi
1. Unduh atau clone repository ini.
2. Salin folder tema ke direktori `wp-content/themes/` pada instalasi WordPress.
3. Buka dashboard WordPress.
4. Pilih menu **Tampilan (Appearance) → Tema (Themes)**.
5. Aktifkan tema **Themes UTS Fiza**.
6. Atur menu utama dan tambahkan artikel beserta gambar unggulan.
7. Buka halaman website untuk melihat hasil tampilan tema.
